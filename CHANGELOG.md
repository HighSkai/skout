# Changelog

All notable changes to Skout are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.5.0] - 2026-11-26

A language engine: every line is parsed down to its sub-expressions, with types.

### Added

- A recursive expression parser that follows `SkriptParser#parseSingleExpr`: parentheses, variables, function calls, text with `%expressions%`, every expression pattern with its slots parsed recursively, arithmetic, and number, boolean and time span literals.
- A type system from Skript's `default.lang`, `DefaultConverters` and `DefaultOperations`, checked closed-world so that conversions an addon could add are never reported.
- Type diagnostics: `invalid-operation` (`5 + "hello"`), `type-mismatch` (`wait "5 seconds"`), `single-value` (`{_list::*} + 1`), `argument-type` (with Skript's own message). Setting: `skout.diagnostics.types`.
- Context diagnostics with Skript's messages: `else`/`else if`/`then` placement and multiline `if` rules, `continue` and `exit` levels, `loop-value` outside a loop, `return` placement, return type and delays, and unreachable code, honouring `suppress unreachable code warnings`. Setting: `skout.diagnostics.context`.
- Command entry validation per version (`EntryValidator`): unexpected entries with a quick fix for misspellings (`atrigger:` → `trigger:`), repeated and missing entries, cooldown entries without a cooldown, root-only entries in 2.17 subcommands, and `permission message` marked deprecated in 2.17. Setting: `skout.diagnostics.entries`.
- Hover for the sub-expression under the cursor, with its type.
- Signature help for function calls.
- Document formatting: re-indentation by depth with the editor's indent, and trailing whitespace removal. Files with indentation errors are left alone.
- Your server: with `skout.server.folder` or a workspace that is the server folder (or inside `plugins/Skript/scripts`), Skout reads the Skript version of the Skript jar, the addons from each jar's `plugin.yml`, the syntax dumps the server generated, and the errors Skript printed in `logs/latest.log`, shown as "Skript (server)" problems. Setting: `skout.server.readLog`.
- The **Skout** view in the activity bar: the Skript version and where it comes from, the server, each addon with whether its syntax is loaded, the syntax dumps in use, how many scripts are checked, and what the server's log reported.
- [How Skout works](docs/architecture.md): the layers, the decisions behind the engine, and its limitations.

### Changed

- Lines are matched against an index of patterns by their leading words, which makes syntax matching several times faster.
- Scripts that are not open are type-checked in the background, a slice at a time.

## [0.4.0] - 2026-11-26

Milestone M4, the upgrade checker.

### Added

- **Skout: Check Upgrade…**: checks every script against a newer Skript (bundled, or downloaded for any version) or a newer dump of an addon, and reports:
  - lines that no longer load, with how the syntax is written now where known;
  - lines that only fit a more general pattern any more;
  - removed expressions inside lines;
  - functions that fail to register, because of a vanished parameter type or a clash with a new built-in;
  - calls to removed built-ins;
  - deprecated syntax;
  - behaviour changes taken from Skript's release notes.
- Upgrade findings in their own Problems collection, cleared with **Skout: Clear Upgrade Results**, plus a Markdown report in `.skout/reports/`.
- A syntax diff between versions, paired by name and pattern, not by id, because ids changed between Skript releases.
- `skout.addonVersions`, to label addon upgrades.
- SkriptHub's `removed_since` markers are honoured when checking an addon upgrade.
- `docs/sample-upgrade-report.md`, a real report generated by `npm run sample-report`.

### Changed

- When several patterns fit a line, the one that starts with fixed words now wins over one that starts with a slot. This makes hover docs more accurate.

## [0.3.0] - 2026-11-26

Milestone M3, Syntax intelligence.

### Added

- Completion for events, effects, conditions, sections, expressions, functions, variables, options and command entries, chosen by where the cursor is. Patterns become snippets with a tab stop per slot, and each alternative of a pattern's leading choice is offered (`login`, `join`, …).
- Hover docs for the syntax a line matches (the most specific pattern wins), with description, example, addon and version.
- `unrecognized-syntax`: misspelled words that make a line match nothing, with a quick fix. In `all` mode, every unmatched line with the closest patterns. Controlled by `skout.unrecognizedSyntax`.
- A port of Skript's pattern compiler and matchers.
- Importers for Skript's `docs.json`, SkriptHub Docs Tool files and SkriptHub's catalog, with format detection and a repair for the invalid JSON in Skript's 2.6.4 to 2.10.2 archives.
- `skout.syntaxDumps` for files or folders of dumps from your own server and addons; a Skript dump from `/sk gen-docs` replaces the bundled one.
- **Skout: Download Syntax Dump**, for Skript's docs or SkriptHub addon syntax, saved to `.skout/syntax/`.
- **Skout: Reload Syntax Dumps**.
- Addon functions from loaded dumps count as known to the function checks.

## [0.2.0] - 2026-11-26

Milestone M2, Project awareness.

### Added

- A background index of every `.sk` file in the workspace, updated per file as you type or as files change on disk, with progress while it builds.
- Go to definition, find references and hover for functions (yours and Skript's built-ins), variables and `{@options}`.
- Workspace symbols for functions, commands and options.
- Cross-file diagnostics:
  - `undefined-function`, `argument-count` and `duplicate-function` (overload-aware from Skript 2.12);
  - `invalid-function`;
  - `unknown-option`;
  - `unset-variable`, with "did you mean" suggestions.
- Rename for functions and for variable names or namespace prefixes, shown in the Refactor Preview before it is applied.
- The **Skout: Variables** view: global variables by namespace and local variables by file and trigger, with every place each is set and read.
- `skout.skriptVersion`, and bundled built-in syntax for Skript 2.14.3, 2.15.4, 2.16.2 and 2.17.1.
- `skout.knownFunctions` for functions that addons provide.
- A language status item showing the targeted Skript version.
- Each new diagnostic category can be switched off under `skout.diagnostics.*`.

### Changed

- Scripts and folders whose names start with `-` are treated as disabled, as Skript does.
- Skript's `config.sk` is not indexed when a workspace contains the server folder.

## [0.1.0] - 2026-11-26

The first release: milestone M1, Foundation.

### Added

- `.sk` files are registered as the `skript` language, with a TextMate grammar, comment toggling, bracket pairs and indentation rules.
- A tolerant parser that builds structures, sections and statements from indentation. It follows the comment and indentation rules of Skript's own config parser.
- Diagnostics:
  - `indent-mixed`, `indent-unexpected` and `indent-style`;
  - `missing-colon`;
  - `unclosed-string`, `unclosed-percent`, `unclosed-bracket` and `unmatched-bracket`;
  - `empty-section`;
  - `unclosed-block-comment` and `accidental-comment`.
- A setting for each diagnostic category under `skout.diagnostics.*`.
- Outline and breadcrumbs for events, commands, functions and `options:` entries.
- Folding by section and `###` block comment.
- An editor-agnostic language server: `node dist/server.js --stdio`.
