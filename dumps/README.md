# Bundled syntax

Built-in Skript syntax, one file per Skript version, in Skout's normalized schema (`server/src/syntax/schema.ts`).

They are generated by `npm run dumps` from the `docs.json` that SkriptLang publishes for each release at `https://docs.skriptlang.org/archives/<version>/docs.json`. That documentation comes from [SkriptLang/Skript](https://github.com/SkriptLang/Skript) and is licensed under the GPL-3.0, like Skout.

Do not edit these files by hand; regenerate them.
